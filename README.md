# ToDo List Full-Stack App (SQL Server Edition)

This project is a full-stack ToDo List application.

## Tech Stack

Frontend:
- Vue 3
- Pinia
- Vue Router
- PrimeVue
- Axios
- AJV

Backend:
- Fastify
- Knex.js
- JWT
- AJV

Database:
- Microsoft SQL Server

## Main features

- Register
- Login
- Logout
- CRUD todos
- JWT authentication & authorization
- User-specific todos
